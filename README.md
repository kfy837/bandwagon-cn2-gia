## CN2、CN2 GT、CN2 GIA……这些到底是什么东西？

先把概念理清，不然买回来踩坑还不知道哪里出了问题。

**CN2**：中国电信下一代承载网，AS 编号 4809，比老的 163 骨干网（AS4134）质量高很多。节点 IP 以 59.43 开头，这是识别标志。

**CN2 GT**：Global Transit，半程 CN2。去程走 CN2，回程在国内出口之后切回 163 骨干，晚高峰照样堵。

**CN2 GIA**：Global Internet Access，全程双向走 CN2 高速节点，去回都不走 163，是电信最高等级的商用国际线路。丢包率低、延迟稳、晚高峰表现明显好于 GT。

**三网回程CN2 GIA**：这才是重点。普通 CN2 GIA 只保证电信用户的回程走 CN2，联通和移动用户各走各的路，优化效果大打折扣。而三网 CN2 GIA 的意思是：联通、移动的数据包在国内先转到电信网，再一起走 CN2 GIA 出国——回程同理，全都经过 CN2 节点回来。

换句话说，用移动宽带的朋友，用三网回程CN2 GIA VPS，和电信用户享受的是同一条线路。
